# Контракт программного интерфейса: `typioca serve`

Версия документа: 1.0. Дата: 19.11.2026. Ветка: `lab-3`.

## 1. Операция

`typioca serve` запускает SSH-сервер, через который удалённый пользователь
проходит тесты typioca. Операция связана с FR-8 и US-8.

Реализация: [`src/cmd/cmd.go`](../src/cmd/cmd.go) (`serveCmd`), обработка ошибок
запуска — [`src/main.go`](../src/main.go). Код приложения не менялся.

## 2. Контракт

### 2.1. Кто вызывает и как

Администратор инсталляции запускает команду из оболочки на машине сервера:

```text
typioca serve [flags]
```

Сам сервер работает без PTY. PTY нужен клиенту: без него SSH-сессия
завершается сообщением `not a tty`.

### 2.2. Входные данные

| Параметр | Тип | Обязателен | По умолчанию | Допустимые значения |
| --- | --- | --- | --- | --- |
| `--bind`, `-b` | строка | нет | `""` — все интерфейсы | IP-адрес или имя хоста |
| `--port`, `-p` | целое | нет | `2229` | `1…65535` |
| `--key`, `-k` | строка | нет | `typioca` | путь к файлу ключа |

Если файла ключа нет, создаётся новый ключ Ed25519.

### 2.3. Условия вызова

- Порт свободен, а каталог для файла ключа существует и доступен на запись.
- На машине разрешены входящие подключения к выбранному порту.
- Встроенной аутентификации нет: подключаться может любой, кто знает адрес.
  Такой сервер нельзя публиковать в интернет без внешней защиты.

### 2.4. Успешный результат

- Команда работает до остановки; успешный запуск определяется по строке журнала
  `Starting server on <bind>:<port>`.
- Клиент с PTY (`ssh -tt -p <port> <host>`) видит обычное меню typioca
  и может пройти тест; результат сохраняется на машине сервера.
- По `Ctrl+C` или `SIGTERM` печатается `Stopping SSH server on <bind>:<port>`.
  Текущая реализация после остановки дополнительно пишет `ssh: Server closed`
  и завершается с кодом `1`.

### 2.5. Поведение при ошибке

Недопустимый или занятый порт — ошибка запуска. Пример:

```bash
typioca serve --port 70000
```

- код возврата `1`;
- stdout пуст;
- в stderr две строки с отметкой времени:
  `Starting server on :70000` и `listen tcp: address 70000: invalid port`.

Ошибку распознают по коду `1` и подстроке `invalid port`.

## 3. Примеры

### 3.1. Успешный запуск

```bash
typioca serve --bind 127.0.0.1 --port 2229 --key typioca
```

Ожидаемый результат: в журнале `Starting server on 127.0.0.1:2229`, при первом
запуске создан файл ключа. В другом терминале:

```bash
ssh -tt -p 2229 127.0.0.1
```

открывается меню typioca. `Ctrl+C` на сервере печатает
`Stopping SSH server on 127.0.0.1:2229`.

### 3.2. Ошибка: недопустимый порт

```bash
typioca serve --port 70000; echo $?
```

Ожидаемый результат: код `1`, в stderr:

```text
2026/11/19 22:12:32 Starting server on :70000
2026/11/19 22:12:32 listen tcp: address 70000: invalid port
```
