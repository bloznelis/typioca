# Журнал изменений

## 1.1 — 18.11.2026

Версия 1.1 документации (лабораторная работа № 3). Код приложения не менялся.

### Добавлено

- `docs/interface-contract.md`: контракт существующей команды
  `typioca completion` с примерами успешного вызова и ошибки.
- `docs/02-cli.md`: описание команд `typioca`, `serve`, `completion` и `help`,
  включая флаги `serve`, поведение ключа и ограничения безопасности.
- FR-10 и US-11: автодополнение командной строки.
- US-10: добавление пользовательского набора слов через TOML (в рамках FR-7).
- Вариант использования «Добавить набор слов» (FR-7) на диаграмме use cases
  для автора наборов и администратора инсталляции.

## 1.0 — 09.11.2026

Версия 1.0 документа требований (лабораторная работа № 2).

### Добавлено

- `docs/01-requirements.md`: описание приложения, FR-1…FR-9, NFR-1…NFR-5,
  сценарии US-1…US-9 и модели системы.
- `docs/diagrams/`: исходники PlantUML и PNG для контекста, деятельности,
  вариантов использования, двух последовательностей, классов и состояний.
- `README.md`: раздел «Запуск», проверка работоспособности и таблица статуса
  требований.
